# AI Rules

Khi sinh giao diện:
Sử dụng các design component đã định nghĩa trong cùng thư mục

- Chỉ dùng token trong foundations.md
- Chỉ dùng component đã định nghĩa
- Không tự tạo màu mới
- Không tự tạo spacing mới
- Ưu tiên ERP/HRM/CRM
- Responsive Mobile First
- Accessibility WCAG AA
- Chỉ dùng 1 Primary Button trên mỗi màn hình
- Form không quá 2 cột
- Table phải có Search + Sort + Filter
